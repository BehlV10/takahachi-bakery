# Takahachi Bakery (Modern Redesign)

A modern, high-craft web rebuild for **Takahachi Bakery** (25 Murray St, Tribeca, NYC) and the unified **Takahachi NYC Family** (Tribeca, SA Brooklyn, and Bakery), originally hosted on Squarespace.

🌐 **Live Demo on GitHub Pages**: **[https://behlv10.github.io/takahachi-bakery/](https://behlv10.github.io/takahachi-bakery/)**

Built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

## ✨ Features & Upgrades

- **Interactive Whole Cake Pre-Order Builder**:
  - Live pricing and serving calculator for 8+ handcrafted celebration cakes (Kyoto Matcha Mousse, Cassis Noir, Strawberry Shortcake, Matcha Mille Crêpe, Soufflé Cheesecake, Belgian Chocolate, etc.).
  - Custom complimentary dark chocolate message plaque piping.
  - Advance pickup scheduler with Monday–Friday validation.
  - Confetti animation and pre-filled email order dispatch.
- **Categorized Café & Drink Menu**:
  - Tabbed filters for Daily Breads (Shokupan, Curry Pan, Ogura Anpan, Melon Pan, Macarons), Japanese Teas (Uji Matcha, Hoji, Genmai, Honey Yuzu), and Espresso/Coffee drinks.
- **Executive Patissiere Spotlight**:
  - Biography and kitchen photo documentation of **Naoko Mabuchi** (French Culinary Institute, 8+ years at 3-star *Bouley* in NYC, Austrian apprenticeship).
- **High-Resolution Photo Gallery**:
  - Full-resolution interactive lightbox inspection with category filters.
- **Critic Reviews & Accolades**:
  - Quotes and ratings from *Time Out New York*, *Serious Eats*, and *Zomato*.
- **Location, Subway Directions & Delivery**:
  - Embedded interactive Google Maps, walking directions from R/W, 1/2/3, and A/C/E subway lines, and direct links to DoorDash, UberEats, and Seamless.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/BehlV10/takahachi-bakery.git
cd takahachi-bakery

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to view the website.

### Production Build

```bash
npm run build
npm run preview
```
